# 记忆与缓存

Agora 把**活跃记忆**注入每场对话的系统提示（`<active_memory_context>`），作为你维护的背景知识（专有名词、身份、稳定偏好）。会话进行中对模型只读，模型不能改原文。只在**设置 → 记忆**里改；清空该段即不再发送。自定义提示词没有记忆变量时，Agora 仍会把这段附在系统提示末尾。

历史对话访问位于**设置 → 对话搜索**，不在记忆页。

若某场对话已经有**会话摘要**（上下文压缩写成的），你改了活跃记忆或该对话绑定的默认提示词，下次发送前 Agora 会要求先更新会话摘要。还没有会话摘要的对话会在下一轮直接用新背景，不必压缩。

记忆在本地保存，直到你删除它；启用的模型使用活跃记忆时，相关内容可能发送给该模型提供商。清理缓存和编辑活跃记忆不是同一操作，请在确认前阅读提示。
