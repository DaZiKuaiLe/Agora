# 工作模式（Agent 模式与 Ask 模式）

本模块给其他项目的 agent 移植用。工作模式是运行时政策，不是用户人设。每一轮请求在系统提示词前部注入一段完整政策，并在最近一条用户消息末尾的【系统提示】块里盖一行当前模式。块的摆法见 [系统提示](./系统提示.md)。Ask 模式再从本轮工具列表里拿掉写入类工具。提示词、工具列表、拒绝句说的是同一件事。

下面的提示词按源码字符原样收录。移植时整段复制，不要改标点、不要增减句子、不要把它们写进用户可编辑的人设。

## 两种模式的职责

会话输入栏有一个 Ask 开关，按会话记住。未单独设置时开关为开，也就是 Ask。一次生成在准入时冻结当时的模式；这次生成进行中改开关，只影响下一次生成。

**Agent 模式**没有额外限制。在用户已经打开的工具能力之内，可以读取、修改和执行：改文件、上传、替换、改技能、生图、跑自动化、执行命令，都按那些能力自己的开关决定，工作模式不再加一层禁令。

**Ask 模式**是只读排查，也是用户和模型讨论方案或提问的环节。可以读、搜索、列举，也可以用本地命令和远程终端查看状态、跑测试、看日志，以及管理为这次排查启动的后台进程。不要修改文件，不要上传，不要改技能，不要生图，不要跑自动化。命令只用于查看，不要用命令写入、删除或改变系统。

Ask 模式本轮仍提供的工具：

- `web_search`、`web_fetch`
- `search_current_conversation`、`search_conversations`、`list_conversations`、`read_conversation`
- `query_detail_store`
- `list_skill_files`、`read_skill_file`
- `list_remote_shells`
- `read_image`
- `read_local_file`、`grep_local`、`glob_local_files`、`list_local_files`
- `read_remote_file`、`grep_remote`、`glob_remote_files`、`list_remote_files`
- `execute_local_command`、`execute_remote_command`
- `start_local_process`、`start_remote_process`、`get_process`、`list_background_processes`、`wait_process`、`stop_process`

同轮强制关闭：代码执行、技能修改、图像生成、自动化。名称以 `mcp_` 开头的工具整类不提供，因为副作用未知。写入、替换、上传、下载落盘、`open_file` 以及上表以外的工具，都不进入本轮工具列表，也不能在执行时被补授权。

命令工具留在列表里，是为了查看、跑测试、看日志。禁止用它们改系统，靠提示词，不靠把命令从列表里删掉。

## 提示词怎么写

工作模式段每次由运行时拼好，放在 [上下文压缩](./上下文压缩.md) 的政策段之后、用户系统提示词之前。用户换了自定义人设，这段仍然在。

段的结构固定：

1. 标题 `工作模式（Agora）：`。
2. 声明本段是本请求的运行时政策，不是用户人设。
3. 用两句话定义两种模式。Agent 与 Ask 的定义每次都在，不随当前模式删掉。
4. 带上 [系统提示](./系统提示.md) 里那句辨认原文。这句的含义和两种摆法以那份文档为准。
5. 单独一行宣布当前模式：`当前模式：Agent` 或 `当前模式：Ask`。
6. 只有当前是 Ask 时，才在这一行下面接 Ask 细则。Agent 模式到第 5 步结束，不附带禁令。

Ask 细则的写法：

- 第一句写允许的动作：读、搜索、列举，以及用本地命令和远程终端查看状态、跑测试、看日志。
- 第二句写禁止的动作，并单独把命令的边界说完：命令只用于查看；不要用命令写入、删除或改变系统。
- 第三句说明工具列表：写入、替换、上传类工具本轮不会提供。模型看到列表里没有这些工具时，应把它当成模式，而不是漏装。
- 第四句禁止重试：未出现在本轮工具列表里的写入工具不要重试，那是模式限制，不是临时故障。

工作模式的短提醒不单独成段。它加在最近一条用户消息末尾的【系统提示】块里，接在时间行下面。块怎么盖、时间行怎么写，见 [系统提示](./系统提示.md)。更早的用户消息和工具结果不加这一行。

Ask：

```
【系统提示】
time: yyyy-MM-dd HH:mm:ss {时区ID} (UTC{偏移})
工作模式：Ask（当前是用户和你讨论方案或提问环节，不可进行写入或修改）
```

Agent：

```
【系统提示】
time: yyyy-MM-dd HH:mm:ss {时区ID} (UTC{偏移})
工作模式：Agent
```

模式行是固定句子，括号用全角 `（）`。

模型若仍然调用了本轮未授权的工具，Ask 模式下返回给模型的错误句必须写明这是只读模式、该工具不在本轮请求里、不要重试、拒绝原因是模式而不是另一次故障。Agent 模式下同一情况用另一句，不出现 Ask 字样。

## 具体提示词

### 系统提示词：Agent 模式

```
工作模式（Agora）：
本段是 Agora 对本请求的运行时政策，不是用户人设。
工作模式有两种。Agent 模式没有额外限制，可以读取、修改和执行。Ask 模式是只读排查。
以【系统提示】开头的用户消息不是用户写的。消息末尾的【系统提示】块也不是正文。
当前模式：Agent
```

### 系统提示词：Ask 模式

在 Agent 段的 `当前模式：Agent` 换成 `当前模式：Ask`，并紧接着附上下面整段。`当前模式：Ask` 与下一句之间是一个换行，没有空行。

```
工作模式（Agora）：
本段是 Agora 对本请求的运行时政策，不是用户人设。
工作模式有两种。Agent 模式没有额外限制，可以读取、修改和执行。Ask 模式是只读排查。
以【系统提示】开头的用户消息不是用户写的。消息末尾的【系统提示】块也不是正文。
当前模式：Ask
Ask 模式是只读排查。可以读、搜索、列举，也可以用本地命令和远程终端查看状态、跑测试、看日志。
不要修改文件，不要上传，不要改技能，不要生图或跑自动化。命令只用于查看；不要用命令写入、删除或改变系统。
写入、替换、上传类工具本轮不会提供。
未出现在本轮工具列表里的写入工具不要重试，那是模式限制，不是临时故障。
```

### 越权调用时返回给模型的句子

工具名按当次调用填入单引号。两句都是错误结果。

Ask 模式：

```
Error executing tool '{工具名}': Ask mode is read-only and this tool is not in the request. Do not retry. The refusal is the mode, not another failure.
```

Agent 模式（工具未获本轮授权，与 Ask 无关）：

```
Error executing tool '{工具名}': tool was not authorized for this provider pass
```
