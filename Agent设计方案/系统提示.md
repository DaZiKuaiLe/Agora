# 【系统提示】

本模块给其他项目的 agent 移植用。`【系统提示】` 是运行时标注块自己的第一行，不是消息的第一行。整条消息以它开头时，它才排在这条消息的最前。贴在末尾时，前面还有正文和一行空行。它不是用户写的，也不是工具结果的正文。

下面这句写在系统提示词里，每一轮都会发给模型，告诉它怎么辨认【系统提示】。

```
以【系统提示】开头的用户消息不是用户写的。消息末尾的【系统提示】块也不是正文。
```

这句话对应两种摆法。下面的标注按源码字符原样收录。移植时整段复制，不要改标点、不要增减句子。

## 整条用户消息以它开头

这条消息角色仍是 user，正文由运行时写成，不是用户打的字。后台进程结束时用这一种：界面上只显示「后台进程已结束」，发给模型的是完整标注。用户消息的前置、后置模板不套到这种消息上。这种消息末尾不再盖第二块。

进程工具的说明里用这一句告诉模型会收到它，并让模型等这条消息，不要轮询：

```
Agora will send a new user message starting with 【系统提示】 when a background process exits with process_id and output — wait for that message instead of polling.
```

后台进程结束时插入的用户消息。`command` 里的换行压成空格。`server` 在本机、空值或本机沙盒时写 `local`，否则写主机名。`ok` 为退出码是 0 且没有 error。`error`、`output`、`stderr` 没有内容就不出现；有内容时，`output` 与 `stderr` 各自空一行再写，仍属于这条运行时消息。

```
【系统提示】
time: yyyy-MM-dd HH:mm:ss {时区ID} (UTC{偏移})
process: 后台进程已结束
process_id: {进程ID}
command: {命令}
server: {local 或主机名}
exit_code: {退出码}
ok: {true 或 false}
error: {错误文本}

output:
{标准输出}

stderr:
{标准错误}
```

## 块贴在消息末尾

正文仍是用户或工具写的。块与正文之间空一行；本条没有正文时，整段就是消息内容。块只加在发给模型的这一份上，不改会话里保存的原文。

末尾块盖在这些消息上：

- 用户消息盖时间。
- 工具结果盖时间。
- 压缩用的触发消息不盖。

时间行不是固定句子。时区 ID 用 IANA 名称，例如 `Asia/Shanghai`。偏移为 `Z` 时写成 `+00:00`，括号内为 `UTC+00:00`。

```
【系统提示】
time: yyyy-MM-dd HH:mm:ss {时区ID} (UTC{偏移})
```
